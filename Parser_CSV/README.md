# Частотный анализ слов с выводом в CSV

##  Описание
Программа принимает на вход текстовый файл, анализирует частоту слов и сохраняет результат в CSV-файл.

### **Формат выходного файла (CSV)**
CSV-файл содержит три колонки:
1. **Слово** – уникальное слово из входного файла.
2. **Частота** – количество вхождений слова.
3. **Частота (%)** – доля слова в тексте в процентах.

Файл упорядочивается по убыванию частоты слов (наиболее часто встречающиеся слова идут первыми).  
Разделителями слов считаются все символы, кроме букв и цифр.

---

##  Запуск
Для запуска программы необходимо передать **два аргумента**:
1. **Имя входного текстового файла** (откуда считывать данные).
2. **Имя выходного CSV-файла** (куда сохранить результат).

### **Пример запуска в терминале:**
```sh
java -jar Parser_CSV.jar input.txt output.csv
```

## 📌 Пример входных и выходных данных
Пример входного файла (input.txt)
```
Привет, мир! Мир большой и прекрасный. Привет всем!
```
### Пример выходного файла (output.csv)
```
Слово,Частота,Частота (%)
привет,2,33.33
мир,2,33.33
большой,1,16.67
прекрасный,1,16.67
```
