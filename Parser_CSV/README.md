В данном проекте реализована программа, которая принимает в качестве аргумента имя текстового файла и выводит CSV файл с колонками:
1. Слово.
2. Частота.
3. Частота (в %).
CSV файл упорядочен по убыванию частоты, то есть самые частые слова
идут в начале. Разделителями считаются все символы кроме букв и цифр.


Аргументы командной строки программы:
> word_count.exe input.txt output.csv


В случаи успешного выполнения программы выводятся логи:

Файлы открылись успешно
Начат процесс заполнение словаря
Словарь создан и заполнен
Начало сортировки словаря
окончание сортировки словаря
Запись словаря в csv файл
Окончание записи словаря в csv файл
Программа выполнена успешно!
